# Legend Online

Everyone should have the freedom to relive their best memories. Reverse engineering should be used to make an alternative possible, not to become a source of income for a few.

The original AS3 client runs in the browser through an AS3 to TypeScript transpiler, a Flash runtime on PixiJS and a Rust server for its protocol.
