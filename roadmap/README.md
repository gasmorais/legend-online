# Roadmap

Feature map of the complete game. Each feature has a folder `roadmap/<feature>/` with a `README.md` and one Markdown file per module, written in technical English for implementation: routes (opcodes and HTTP paths), protobuf messages, client classes with `file:line`, server responses, rules, templates, PostgreSQL tables and an implementation checklist.

Generated by `tools/featuremap.py`. Every client package and every protobuf package is assigned to exactly one feature. The coverage audit is in [COVERAGE.md](COVERAGE.md) (generated by `tools/coverage.py`), the conventions are in [CONVENTIONS.md](CONVENTIONS.md), the opcode name index is in [OPCODES.md](OPCODES.md) and the per-feature text maps are in each `texts.md` (generated by `tools/textmap.py`).
