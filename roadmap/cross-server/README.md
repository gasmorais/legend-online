# Cross-server contests ("Disputas inter-servidor")

Feature slug `cross-server`, domain pvp. The registry groups several small systems that span servers:

| Module | pt-BR name | Client package | Protocol |
|---|---|---|---|
| [consumption-ranking.md](consumption-ranking.md) | "Consumo do Povo" / "Rank de consumo inter-servidor" | `crosscost` | 9602 / 345 `active.ChargeRewardMsg`, funny activity types 197 and 73, ranking file `consumrank_unzip.xml` |
| [recharge-ranking.md](recharge-ranking.md) | "Recarga Total" / "Ranking de Recarga Inter-Serv." | `exchargerank` | 8866 / 4745 `ChargeRewardMsg`, funny activity types 196 and 67, ranking file `chargerank.xml` |
| [hephaestus-ore.md](hephaestus-ore.md) | "Minério de Hefesto" | `stokesore` | 9645 `OreActiveClientOpMsg`, 187 to 190 |
| [bloody-realm.md](bloody-realm.md) | "Inferno Sangrento" | `map.campaign.*.bloody` | `bloodyrealm` package, 9588 / 333, 9589 / 334, 335 |
| [fantasy-matrix.md](fantasy-matrix.md) | "Formação Mágica" | `map.campaign.mediator.fantasymatrix` | `fantasymatirx` package, 8473, 4448, 4449 |
| [cross-bugle.md](cross-bugle.md) | "Megafone Inter-S" | chat | `cross.CrossBigBugleMsg` (mapped in [../chat/bugles.md](../chat/bugles.md)) |

PostgreSQL schema `cross_server`. Rust handlers `cross_server::<module>::handle_<action>`.

Common cross-server conventions (assumptions, shared with [../league/README.md](../league/README.md) and [../three-kingdoms/README.md](../three-kingdoms/README.md)):

- Opcodes named `CR_*` (for example 25041, 25131, 25133) are routed by the game server to a cross service; responses come back through the player's game server connection.
- A player is identified across servers by `(server_name or server_id, user_id)`; rows that store foreign players keep both and do not reference `player.players`.
- Ranking files under `{TPL}` (`routes/routes.md`: `orderPath` = `{TPL}`, served from `/cdn/xml/` locally) are regenerated by the server every hour; the root element carries `<info createDate="YYYY-MM-DD hh:mm:ss.fff"/>` and the client reloads only when the current hour differs from the file hour.

## Dependencies

- [../seasonal-events/README.md](../seasonal-events/README.md): the generic activity engine "funny" (4475 `U_C_SUM_ACTIVE_TEMP` `SumActivesMsg`, 4476 `U_C_SUMACTIVE_DATA` `SumActiveDataMsg`, 8586 `C_SUMACTIVE_GATE` `SumActiveGetPackageMsg`) carries the reward packages and claim states of the consumption and recharge rankings.
- [../recharge/README.md](../recharge/README.md) and [../currency/README.md](../currency/README.md): diamond recharge and consumption totals feed the rankings; diamonds pay the ore mining.
- [../campaign/README.md](../campaign/README.md): room hall, instance creation, map engine for maps 9996 and 9997; 4665 `DragonCampaingnDataMsg` and 4945 random boss buffs are shared with the dragon (Molong) activity.
- [../trials/README.md](../trials/README.md): Molong / random boss mechanics reused by the bloody realm (`RandomShaiziManager extends MolongManager`).
- [../battle/README.md](../battle/README.md): battle types 3854 `BLOODY_REALM_BATTLE`, 3862 `FANTASY_MATRIX_BATTLE`, 3842 `RANDOM_BOSS`.
- [../hero/README.md](../hero/README.md): player info 3 `PlayerMsg` counters `fantasyMatrixCampaignCount` (#131), `fantasyMatrixCampaignMaxCount` (#132), `bloodyRealmCampaignCount` (#133), `bloodyRealmCampaignMaxCount` (#134).
- [../inventory/README.md](../inventory/README.md), [../mail/README.md](../mail/README.md): rewards, ore treasure prizes by mail.
- [../chat/README.md](../chat/README.md): ore result lines rendered with chat markup (channel 110), cross bugle.
- [../vip/README.md](../vip/README.md): VIP only reward packages of the rankings.
