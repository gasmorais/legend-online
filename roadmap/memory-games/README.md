# Jogos de memória (memory games)

Client packages `newmemorycard` (m11 UI, core model) and `sqmemory` (m11 UI, core model); protobuf packages `memorycard` (`NewMemoryCardMsg`) and `sqmemory` (`SqMemoryUserMsg`).

| System | pt-BR | What the player does |
|---|---|---|
| Memory card | "Jogo da memória" | During an event, flip pairs on a 4x6 board with daily free steps and bought steps; matched pairs give rewards; refresh after the special pair |
| Anniversary review | "Começo da Aventura" ... "Viagem Lendária" (周年回顾) | Level 80+: read a personal review book generated by the server, pick a tag, share the card to Facebook for a one time reward |

All game traffic is socket based; the review share uses one HTTP upload (`{REQ}sqshare`). PostgreSQL schema: `memory_games`. Rust handlers: `memory_games::<module>::handle_<action>`.
