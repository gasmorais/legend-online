## How to read this

| Column | Meaning |
|---|---|
| Screen | Fully qualified AS3 class name |
| Title (pt-BR) | Title text resolved through `index/language.json`, or the raw language key when no text exists; truncated to 50 characters |
| Kind | **frame**: subclass of `com.pickgliss.ui.controls.Frame` (window or dialog). **scene**: subclass of `yishi.scene.BaseSceneView` (full-stage state switched by `SceneManager`). **tip**: subclass of `yishi.view.tips.BaseTip` (tooltip) |
| Module | Decompiled module that defines the class; links to its UI module page |
| Extends | Direct superclass (simple name) |
| Size | `width×height` from the screen style, or from its `backStyle` part when the style has no size |
| Styles | Style entries resolved for the screen and its subviews |
| Subviews | Display classes instantiated by the screen, followed transitively up to 4 levels |
