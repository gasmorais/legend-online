# Manager classes

Managers are long-lived objects, mostly singletons, that hold client state and rules (bag, battle, chat, scenes,
socket traffic). This page lists every class whose name ends in `Manager` or `Mgr`, across all
decompiled modules. Generated by `tools/map.py`.

Related: [architecture overview](../overview/architecture.md), [PickGliss components](components.md),
[screen index](../ui/screens.md), [navigation map](../ui/navigation.md).
