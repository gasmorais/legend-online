# PickGliss UI components

PickGliss (`com.pickgliss.ui`) is the UI framework of the client: controls, images, text fields and the
`ComponentFactory` that builds them from named styles. This page lists every class of the framework found
in the core module, grouped by sub-package. Generated by `tools/map.py`.

Related: [UI composition](../ui/README.md) (how styles become components),
[screen index](../ui/screens.md), [managers](managers.md), [renderer](renderer.md).
