# Client HTTP routes

Every HTTP address the client builds: the base URLs from `raw/config.xml`, the servlet endpoints
appended to `{REQ}`, and the resource path templates of `PathManager`, each checked against the CDN
manifest. Generated by `tools/map.py` with `tools/paths.py`; full data in `routes/routes.json`.

Related: [AMF remoting](../protocol/amf.md), [socket protocol](../protocol/socket.md),
[architecture overview](../docs/overview/architecture.md).

The CDN serves a resource at `https://res1264oas.creaction-network.com/<path>_<md5>.<ext>`, where
`<md5>` is the truncated hash from the manifest; a request without the hash returns 403.
The manifest stores paths in lowercase.
